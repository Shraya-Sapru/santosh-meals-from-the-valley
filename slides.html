The problem

My mother, Meenakshi Sapru, has wanted to start a home supper club in Bangalore cooking Kashmiri Pandit food — something we'd been discussing for a while but never had the tools to launch. It's a distinct culinary tradition (no onion, garlic, or tomato) that almost nobody in the city has actually encountered.

  • Discovery: no way for a stranger to learn what this food even is, or trust a home kitchen is cooking it right
  • Booking: no real reservation system for the handful of seats a pilot evening could offer
  • Source material: exactly one private family Word document, never digitized before this project

The real story: the LLM only runs in the one-time admin pipeline. Browsing, cooking the simulation, and booking a seat are zero-LLM-call code paths. Marginal cost per user — at 100 or 10,000 users/month — is $0, not "small."

Safety: the onion that wasn't there

Extracting Kashmiri Dum Aaloo, the model invented "onion, finely chopped" — an ingredient that appears nowhere in the source, which explicitly states Kashmiri Pandit cooking skips onion entirely.

Caught automatically: Found forbidden ingredient 'onion'... Kashmiri Pandit cuisine never uses onion, garlic, or tomato. — a hard flag; the recipe could not be approved while it was present.

34 seconds later, a clean re-extraction removed it. Plus: nothing publishes without human approval, regardless of flags.

Impact

  • 7 of 7 family recipes digitized — previously existed only in one private document
  • A real seat, really booked: 2 seats, ₹3,600, confirmed — 25% of the pilot evening's capacity, before any public launch
